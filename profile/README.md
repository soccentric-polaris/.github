# Polaris

Open-source embedded Linux platform for **Renesas RZ/G2L**, from [SoCcentric](https://github.com/Soccentric).
MIT licensed.

| Repository | Purpose |
|---|---|
| [Polaris-OS](https://github.com/soccentric-polaris/Polaris-OS) | Yocto/kas image build |
| [meta-polaris](https://github.com/soccentric-polaris/meta-polaris) | Yocto layer for the board |
| [Polaris-HAL](https://github.com/soccentric-polaris/Polaris-HAL) | Hardware abstraction layer (C++17) |
| [Polaris-Client](https://github.com/soccentric-polaris/Polaris-Client) | gRPC client (C++17) |
| [Polaris-Server](https://github.com/soccentric-polaris/Polaris-Server) | Test server (Drogon, C++) |
| [Polaris-Configuration](https://github.com/soccentric-polaris/Polaris-Configuration) | WebConfig on-device configuration |
| [Polaris-Dashboard](https://github.com/soccentric-polaris/Polaris-Dashboard) | HTML5 dashboard |
| [Polaris-PySDK](https://github.com/soccentric-polaris/Polaris-PySDK) | Python SDK |
| [Polaris-Instrumentation](https://github.com/soccentric-polaris/Polaris-Instrumentation) | On-device management and observability |
| [Polaris-HQ](https://github.com/soccentric-polaris/Polaris-HQ) | Fleet management |
| [Polaris-Hardware](https://github.com/soccentric-polaris/Polaris-Hardware) | Hardware documentation |

Contributions go to the `develop` branch. See the shared [contributing guide](https://github.com/soccentric-polaris/.github/blob/main/CONTRIBUTING.md).
